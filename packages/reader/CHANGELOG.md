# @tetsustudio/reader

## 0.1.0

### Minor Changes

- First release of `@tetsustudio/reader`, ported from glimpse: `PdfReader` (page, text and OCR views), `EpubReader` (search, read aloud, translation) and `Reader`, with `onProgress`/`initialProgress`, `translate`, `onExit`, `storage` and `labels` adapters, the `tetsu-reader-assets` bin for pdf.js and tesseract files, and token-based precompiled CSS.
