# @tetsustudio/editor

## 0.1.0

### Minor Changes

- First release of `@tetsustudio/editor`, extracted from forge: `CollaborativeEditor` (Milkdown on a Y.Doc and awareness the app provides), `MarkdownEditor`, `PlainTextEditor`, `EditorToolbar`, `SearchBar`, `SpellcheckSettings` and `ImageLightbox`, with `uploadImage`, `storage`, `dictionaryBaseUrl` and `labels` adapters (English defaults, `esLabels`), the `tetsu-editor-dictionaries` bin, and a headless `@tetsustudio/editor/server` entry for the schema, markdown codec and Y.Doc helpers.
